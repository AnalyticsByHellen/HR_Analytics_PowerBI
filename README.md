# HR_Analytics_PowerBI
Power BI HR analytics project analyzing employee demographics, attrition, job roles, job satisfaction, and workforce trends.

## Project Overview

This project analyzes employee data using Power BI to understand
workforce demographics, employee attrition, job roles, satisfaction,
and other HR performance indicators.

## Business Questions

- What is the overall employee attrition rate?
- Which departments have the highest attrition?
- Which job roles have the highest attrition?
- Does employee age relate to attrition?
- How does job satisfaction vary across roles?
- Which employee groups have the highest attrition?
- How does monthly income differ across job roles?
- What factors are associated with employee turnover?

## Key KPIs

- Total Employees
- Attrition Rate
- Employees Who Left
- Average Employee Age
- Average Monthly Income
- Average Job Satisfaction

## Tools Used

- Power BI
- Power Query
- DAX
- Excel/CSV

## Analysis

The dashboard provides interactive analysis of employee demographics,
attrition, job roles, income, and satisfaction.
